## 👨‍💻 Sobre mí

Soy un desarrollador con foco fuerte en **desarrollo backend** y **diseño de sistemas distribuidos**, expandiendo mis capacidades hacia el desarrollo **Frontend moderno** e infraestructura. Me apasiona construir APIs robustas, documentadas y escalables, arquitecturas distribuidas resilientes y conectarlas con interfaces de usuario sólidas y eficientes.

- ⚙️ Construyendo microservicios robustos con **Spring Boot + Spring Cloud**
- 📐 Diseñando e integrando contratos de APIs claros usando **Swagger / OpenAPI** y testeando con **Postman**
- ⚛️ Desarrollando interfaces interactivas y escalables con **React + Redux (State Management)**
- 🔄 Diseñando sistemas event-driven de alta disponibilidad con **Apache Kafka**
- 📊 Implementando observabilidad, métricas y monitoreo con **Prometheus + Grafana**
- 🐍 Creando APIs REST rápidas y eficientes con **FastAPI + Python**
